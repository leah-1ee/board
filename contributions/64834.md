## 문제 내용

- **문서**: `offset`/`size` 단위가 타입마다 다른데(TypedArray는 원소, ArrayBuffer/DataView는 바이트) 문서는 `buffer.length - offset` 하나로만 서술 → `.length` 없는 타입엔 무의미
- **테스트**: 위치 검증이 전부 1바이트 타입뿐 → multi-byte의 원소→바이트 변환이 미검증

## 해결 과정과 검증

→ 문서 수정 + multi-byte 테스트 추가로 PR 제출

멘토님 의견 : core js 코드 상에 문제가 있고, 랜덤값 기반 테스트라 flaky 가능성 있음

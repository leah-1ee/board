## 문제 내용

두 번째 PR에서는 `run({ env })`에 잘못된 값을 넣었을 때 `ERR_INTERNAL_ASSERTION`이 나오는 문제를 수정했습니다. 원인은 `validateObject()`에 옵션 이름이 빠진 것이었고, 잘못된 입력 **11종**에 대한 테스트도 같이 추가했습니다.

## 해결 과정과 검증

```diff
- validateObject(env);
+ validateObject(env, 'options.env');
```

## 문제 내용

- QUIC 세션 종료 시 통계 데이터를 복사하는 과정에서 스트림 통계 개수를 잘못 사용해 `cwnd` 이후 일부 세션 통계가 `undefined`로 사라지는 문제를 수정했습니다.

## 해결 과정과 검증

- 세션 통계 전체 개수를 기준으로 복사하도록 변경하고, 세션 종료 후에도 `cwnd`와 마지막 통계 필드가 유지되는지 검증하는 회귀 테스트를 추가했습니다. 해당 PR은 리뷰 승인을 받은 뒤 `main` 브랜치에 병합되었습니다.

## 문제 내용
Node.js의 `internalBinding('profiler')`에 대한 타입 선언이 `typings/internalBinding/`에 없었습니다.

## 해결 과정과 검증
`setCoverageDirectory`, `setSourceMapCacheGetter`, `startCoverage`, `takeCoverage`, `stopCoverage`, `endCoverage`를 포함한 `ProfilerBinding` 타입을 작성하고, `typings/globals.d.ts`의 `InternalBindingMap`에 등록했습니다.
각 멤버를 C++ 등록 코드(`src/inspector_profiler.cc`)와 대조하고, `--expose-internals`로 실제 바인딩 값을 확인해 검증했습니다.

## 배운 점
정확한 선언을 작성하기 위해 실제 C++ 등록 코드와 런타임 값까지 대조해야 한다는 걸 배웠습니다.
